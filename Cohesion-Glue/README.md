# COHESION — GLUE

Original JUCE/VST3 plugin by **Pepperwood** — part of the [COHESION](../README.md) suite.

A master-bus **glue compressor**: gentle, musical bus compression (with oversampling and
a lookahead limiter) to pull a mix together. This is the first plugin of the suite and
set the shared dark/teal house style.

## Build

```bash
cmake -S . -B build
cmake --build build --config Release
```

JUCE 7.0.12 is fetched automatically (or reused from a sibling Cohesion project).
